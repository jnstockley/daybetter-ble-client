# P031 and P065 Support Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Automatically discover and control P031 and P065 devices through the existing API.

**Architecture:** Immutable model profiles select UUIDs and protocol differences. P065 performs a validated, bounded challenge handshake after enabling notifications. Existing P031 defaults remain intact.

**Tech Stack:** Python, Bleak, bleak-retry-connector, standard-library unittest.

**Spec:** ../specs/2026-11-15-p065-support-design.md

## Global Constraints

- Preserve existing P031 constructor usage, constants, and command packets.
- No automatic reconnect policy, UI, daemon, or other model support.
- Distinguish acknowledgements from observed device behavior.

## Review Focus

- Conflicting service/name identifiers: advertised supported service takes precedence.
- Handshake failure, corruption, and timeout: no control commands, clean disconnect.
- Repeated device updates: reconnect using the selected model without retaining authentication.
- Multiple devices: listeners and handshake state remain separate.
- Exceptions during example commands: always release the BLE connection.
